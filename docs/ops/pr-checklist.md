# PR checklist

- [ ] Alcance acotado y sin mezclar refactors no relacionados
- [ ] Tipado estricto sin `any`
- [ ] Tests minimos agregados/actualizados
- [ ] Logs y errores accionables
- [ ] Multitenancy enforcement validado
- [ ] Seguridad de headers y auth validada
- [ ] Documento ADR actualizado si cambia arquitectura
